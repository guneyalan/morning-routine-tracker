# Morning Routine Tracker

Et simpelt Python-eksamensprojekt, hvor brugeren kan registrere sin morgenrutine og få statistik samt AI-feedback.

## Teknologier

- Streamlit
- FastAPI
- Pandas
- NumPy
- Matplotlib
- Requests til LLM API
- Pytest
- Mypy
- Ruff
- Docker Compose

## Funktioner

- Registrering af morgenrutine
- Valg af bad: normalt bad, koldt bad eller intet bad
- Gemmer data i CSV
- Viser historik i tabel
- Viser statistik
- Viser graf over humør
- Genererer AI-feedback
